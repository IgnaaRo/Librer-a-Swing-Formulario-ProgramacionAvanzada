Este trabajo práctico consiste en crear un formulario de contacto en Java usando Swing. El formulario permite ingresar datos como nombre, apellido, DNI o pasaporte, teléfono, código postal y domicilio.

Se aplican validaciones para controlar que los datos sean correctos, por ejemplo que solo se ingresen letras en nombre y apellido, números en DNI y código postal, y que no se completen DNI y pasaporte al mismo tiempo.

Además, el sistema tiene botones para validar los datos, limpiar los campos y cerrar la aplicación.
